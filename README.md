
# Nudraulix Manual Testing Bug Report

## Project Overview
This repository contains the manual testing bug report and QA documentation for the **Nudraulix** web application. The testing focused on identifying functional defects, UI/UX inconsistencies, workflow issues, validation problems, and usability concerns across key areas of the platform.

The report is based on structured manual testing documentation prepared in Excel format.

## Types of Testing Performed

### Functional Testing
Validated core application features and checked whether each workflow worked according to the expected behavior.

### UI/UX Testing
Reviewed layout consistency, spacing, alignment, button styling, visibility, responsive behavior, and overall usability.

### Browser Compatibility Testing
Checked the application behavior across browsers to identify layout or functionality differences.

### Workflow Testing
Tested complete user flows such as login, registration, product browsing, cart actions, checkout, order creation, and order management.

### Regression Testing
Verified previously reported issues and checked whether fixes were properly implemented without affecting existing features.

---

## Key Issues Identified

During testing, the following types of issues were identified:

- Misaligned dropdowns and buttons
- Missing hover effects and cursor indicators
- Non-functional social media icons
- Search returning irrelevant results for special characters
- Missing product images
- Static featured products section
- Inconsistent footer design across pages
- Missing product details and catalog information
- Duplicate quantity controls
- Non-working list view, sorting, and pagination controls
- Checkout and cart workflow issues
- Login and registration validation issues
- Address, favourites, contacts, and order-related functional issues
- Visibility and UI consistency problems

## Bug Report Format

The Excel bug report includes the following columns:

| Column | Description |
|---|---|
| SL | Bug serial number |
| Module | Application module or section |
| Type of Testing | Testing category |
| Feature | Feature or page being tested |
| Test Cases | Test scenario or bug title |
| Expected Result | Expected application behavior |
| Actual Result | Observed application behavior |
| Reproducing Steps | Steps to reproduce the issue |
| Screenshot | Screenshot or video reference |
| Priority | Issue priority level |
| Status | Current issue status |
| Remark | Additional QA note |

---

## Priority Classification

- **High Priority:** Issues that directly affect core functionality, workflow completion, data accuracy, or user access.
- **Medium Priority:** Issues that affect usability, consistency, or partial functionality.
- **Low Priority:** Minor UI/UX issues or improvements with limited functional impact.
